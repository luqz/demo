## 1. 产品概述 (Product Overview)

### 1.1 产品定位

`add` 是一个极简命令行工具，接受两个整数参数，输出它们的和。无子命令、无交互模式、无配置文件。唯一目的：在终端里快速算加法。

### 1.2 核心价值主张

| 维度 | 说明 |
|------|------|
| 速度 | 二进制启动 + 计算在 100ms 内完成 |
| 零依赖 | 单二进制，无运行时依赖，复制即用 |
| 正确性 | 覆盖零值、负数、大整数、溢出、非法输入等边界条件 |
| 跨平台 | 支持 linux/amd64, linux/arm64, darwin/amd64, darwin/arm64, windows/amd64 |
| 无噪音 | 正常输出仅结果，错误输出仅错误信息 |

### 1.3 目标用户

| 角色 | 场景 | 动机 |
|------|------|------|
| 开发者 | 终端快速计算两个数值 | 不想打开计算器或 Python REPL |
| 脚本编写者 | Shell 脚本中做整数加法 | 需要可靠、可管道串联的 CLI |
| CI 系统 | 构建流水线中计算数值（计数、偏移量等） | 需要可预测的退出码和 stdout 输出 |

### 1.4 项目假设

| # | 假设 | 如果假设不成立 |
|---|------|---------------|
| A1 | 用户输入均为有效整数（在 int64 范围内） | 工具需返回明确错误信息和非零退出码 |
| A2 | 用户期望极简 CLI，不需要交互模式 | 若反馈需要交互，v2 可扩展 |
| A3 | Go 1.21+ 在构建环境可用 | 降级到更低版本需调整 `go.mod` |
| A4 | 目标平台为 linux/darwin/windows × amd64/arm64 | 其他平台按需添加 |
| A5 | 项目仓库仅为该单一工具服务 | 若未来加入其他工具，需重构为 monorepo |

## 3. 验收标准 (Acceptance Criteria)

### 3.1 核心功能验证

- [ ] `add 2 3` → stdout: `5`, exit: `0`
- [ ] `add 0 0` → stdout: `0`, exit: `0`
- [ ] `add -5 10` → stdout: `5`, exit: `0`
- [ ] `add -7 -3` → stdout: `-10`, exit: `0`
- [ ] `add 2147483647 1` → stdout: `2147483648`, exit: `0`（大整数）
- [ ] `add 9223372036854775807 1` → stderr 含溢出错误信息, exit: `1`（int64 溢出）
- [ ] `add -9223372036854775808 -1` → stderr 含溢出错误信息, exit: `1`（int64 负溢出）

### 3.2 错误路径验证

- [ ] `add` (无参数) → stderr: `Error: 缺少参数，需要两个整数。用法: add <a> <b>`, exit: `1`
- [ ] `add 1` (缺一个参数) → stderr: `Error: 缺少参数，需要两个整数。用法: add <a> <b>`, exit: `1`
- [ ] `add 1 2 3` (多余参数) → stderr: `Error: 参数过多，仅接受两个整数。用法: add <a> <b>`, exit: `1`
- [ ] `add abc 1` (非整数) → stderr: `Error: "abc" 不是有效整数`, exit: `1`
- [ ] `add 1 xyz` (非整数) → stderr: `Error: "xyz" 不是有效整数`, exit: `1`
- [ ] `add 1.5 2` (浮点数) → stderr: `Error: "1.5" 不是有效整数`, exit: `1`

### 3.3 帮助与版本验证

- [ ] `add --help` → stdout 含用法说明（命令格式 + 参数说明），exit: `0`
- [ ] `add -h` → 等同于 `add --help`
- [ ] `add --version` → stdout: `add v1.0.0`, exit: `0`
- [ ] `add -v` → 等同于 `add --version`

### 3.4 管道输入验证

- [ ] `echo "3 4" | add` → stdout: `7`, exit: `0`
- [ ] `echo "3" | add` → stderr: `Error: 缺少参数，需要两个整数。用法: add <a> <b>`, exit: `1`
- [ ] 无输入且无参数时（`add </dev/null`）→ stderr: `Error: 缺少参数，需要两个整数。用法: add <a> <b>`, exit: `1`

### 3.5 代码与构建验证

- [ ] `go.mod` 声明 Go 版本 ≥ 1.21
- [ ] 主代码文件 ≤ 100 行
- [ ] 存在 `add_test.go`，覆盖 3.1-3.4 所有用例
- [ ] `go vet ./...` 无警告
- [ ] 跨平台编译通过: `GOOS=linux GOARCH=amd64 go build`, `GOOS=darwin GOARCH=amd64 go build`, `GOOS=darwin GOARCH=arm64 go build`, `GOOS=windows GOARCH=amd64 go build`, `GOOS=linux GOARCH=arm64 go build`

### 3.6 退出码规范

| 退出码 | 含义 |
|--------|------|
| 0 | 成功，结果输出到 stdout |
| 1 | 用户输入错误（参数缺失、格式错误、溢出） |
| 2 | （预留）运行时错误（写 stdout/stderr 失败等） |

## 4. 明确不做 (Out of Scope)

| # | 排除项 | 决策 | 说明 |
|---|--------|------|------|
| D-01 | 浮点数/小数加法 | 不做 | 仅处理整数，输入浮点数视为格式错误 |
| D-02 | 交互模式 / REPL | 不做 | 纯命令行，一次调用一次计算 |
| D-03 | 减法、乘法、除法等其他运算 | 不做 | 仅加法，保持工具单一职责 |
| D-04 | 三个及以上操作数 | 不做 | 严格两个整数，多余参数报错 |
| D-05 | 结果格式化（逗号分隔、十六进制等） | 不做 | 输出纯十进制整数 |
| D-06 | 配置文件 / 环境变量配置 | 不做 | 零配置设计 |
| D-07 | 大数 / big.Int 任意精度 | 不做 | 限制在 int64 范围，溢出报错 |
| D-08 | 从文件读取输入 | 不做 | 仅支持命令行参数和 stdin |
| D-09 | 本地化 / i18n | 不做 | 所有消息为中文 |
| D-10 | 安装脚本 / 包管理器发布 | 不做 | 仅提供源码 `go build` / `go install` |
